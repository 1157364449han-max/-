# 董解析分阶段更新计划

## 当前基线：0.51.3

0.51.3已落实弧段、象限、区间、分支和分问驱动位置，并给旧参考题稿提供先备份再升级入口；不迁移云端。下一批优先补自由输入推理与建图缺口，继续区分参考讲解、AI生成和独立核验；不把未识别的自然语言条件宣称为自动约束。

## 当前增量：0.48.0 圆弦折叠

已落实用户原图的圆方程、定值点和折叠长度范围，参数化独立复算与原题空间展示共用数学模型。电脑/手机视窗可切平面和空间、调动弦和旋转视角；没有新增远程依赖。仅覆盖圆心在 x 轴、原点在圆内的过原点弦沿 x 轴折叠，不宣称一般立体题全支持。下一阶段以真实原题扩充构型，空间辅助面、坐标卡和更一般的解答语义仍有待完善。

## 第一阶段：0.42.0 使用已有 AI（已发布）

- 本机解题默认改为复制粘贴；保留“内置数学引擎”和“已下载模型”两种其它方式，不删除功能。
- 请求在浏览器生成，原题与 LaTeX 原样保留；不需要网站预先解出方程，不调用模型 API。
- 用户将请求发给自己使用的 AI，复制完整回复回来，先预览再确认导入。
- 校对请求标识、小问编号、数据类型、引用、依赖循环和当前位置的几何存在性；普通文字保留原文，不假称已经得到完整证明或可靠图形。
- 图形使用白名单构造，动点、切线、法线、交点、中点、垂足、对称点保持依赖关系；不执行 AI 代码或加载其链接。
- 复制补充/修正请求、浏览器复制被拒时选中文本、保存请求文本；错误回复和取消不替换原题稿。
- 外部模型账户仍可能有收费、使用和网络限制；董解析不扣其平台云端次数。

操作：输入原题 → 解题扩展键选择“本机解题” → 点“解题” → 复制解题请求 → 发给已有 AI → 粘贴完整回复 → 校验与预览 → 确认导入。

## 第二阶段：0.43.0 正确率和图形完整性（首批实现）

- 以有出处的真实高考题回归，不用预置答案冒充通用解题能力；记录各小问的缺答、矛盾、未核验和图形缺失。
- 扩大独立代数核验覆盖，严格区分“求解困难”“题目条件不足”和“动态图形不唯一”。
- 已实现缺失点线报告、共享小问图层、统一云端与粘贴构造协议、根号系数修复及部分独立复算。原卷回归见 0.43.0-验证记录.md。
- 本批用 12 道不同真题、18 个小问建立基线；内置规则的完成标记不是总体正确率。尚需扩展至 20–30 道不同原卷题，补齐未覆盖证明和复杂轨迹。
- 0.43.1 实际云端回归抓到未知分母符号错误，新增原题渐近线恒等式复算与原始答案保留；同一基线内置完成标记为 8/18。正式模型实测与内置覆盖分开记录。
- 0.43.2 实际云端回归抓到派生图形的隐藏依赖漏合并，改为完整依赖闭包与稳定标识替换；不把答案正确等同于画图已通过。
- 0.43.3 修正过小的流式传输上限，保留正文和超时保护。连接成功、完整传输、答案正确与图形正确分别验收，不把 HTTP 200 当作成功解题。
- 0.44.0 完成点名自动避让、真实重合名称合并与手机专项测试；解析步骤可按名称定位已有可见图形，明确缺失与隐藏项。名称匹配不是完整语义理解或一般性证明。
- 下一阶段继续扩大有出处原卷回归、补齐独立证明与复杂轨迹核验，以及更精确的步骤—构造语义对应。
- 0.45.0 完成等距定义抛物线与通用矩形周长严格下界证明，既有真题内置完成标记从 8/18 到 11/18（12 道不同题；不是一般正确率）。切线及多边形的未覆盖复合目标不再误报完整解答。动态图形显示点、垂足、矩形并支持构型参数选择。
- 0.46.0 完成等轴双曲线的符号递推、坐标差等比证明、面积不变量和真实交点—反射联动；参数入口按需展开，极端绘图参数明确提示。真题完成标记和严格核验分开报告。
- 同一组 12 道不同题、18 个小问的内置完成标记到 14/18；2024 全国Ⅱ卷19题的缺项误报已修正，剩余未建图的原卷输入为 2022 北京10题。仍不是通用全题正确率。
- 下一阶段优先补平面动点的向量数量积范围、极值位置高亮及已有图形的步骤对应；继续扩展有出处的真题回归，不以预存答案扩充完成率。
- 加强极值取等位置、轨迹定义域、特殊情形及退化构造的展示与说明。
- 0.47.0 优先修复用户实际输入中的前问引用误拆，将编号识别作为各解题路径的共享模块；补齐焦点弦长与中点反求抛物线、后问约束传递和准线正交点依赖图，不按题号查答案。下一阶段仍优先向量数量积范围与扩大真实原卷回归。

## 第三阶段：云端视觉与用户自带 AI

0.47.1 发布前优先修复草稿基准、对象误删、目标覆盖、AI 回复协议、依赖合并、授权/连接状态、配额受理顺序与离线/更新安全。当前公开入口按用户要求暂时仅保留云端解题，本机代码保留但入口隐藏；先验证正式网页和 D 盘一致，再扩展其它阶段。

0.47.2 优先修复手机网络切换、迟到的流式授权与健康回复；使用有界语法读取最终答案的明确辅助构造，并展示缺失对象、当前退化和已有同名点关系冲突。题干/答案/画板一致性仍需扩展，不是通用语义理解或一般证明器。后续继续原卷独立核验、复杂轨迹与实际手机体验，不改变访问口令、模型、额度或费用。

- 适配官方支持视觉的模型；图像上传需要用户明确选择，识别后确认，保留本地 OCR。
- 用户自带 API 首先使用官方支持的服务及固定域名白名单；其它协议逐项适配，不接受任意代理地址转发密钥。
- 默认短期授权，不把凭证放进公开代码、普通本地存储、日志或截图；用户知道请求与凭证会经过哪些服务，能够撤销。
- 用户自带凭证不占管理员提供的共享推理额度，但平台与模型服务商限流继续有效。普通聊天软件账号不等于 API 权限。

## 第四阶段：用量及教育体验

- 管理员专用用量面板：请求、token、费用估算和配额；共享访问口令不能用来修改管理员的付费配置。
- 配额上调须单独确认，次数不是金额硬上限；保留并发、防滥用和异常反馈。
- 学生模式强化分步提示与错因定位；教师模式强化演示、步骤联动画板、课堂投屏与已有题库入口。
- 电脑和手机使用同一个发布版本，保持可收起的设置与工具，继续移动端触控、离线和更新回归。

以上未标记完成的阶段都是后续工作，不代表已上线。本轮访问口令、云端配额及模型凭证不变更；轻量云端接口与浏览器版本可以独立升级。
