# 0.51.3 验证记录

2026-10-04。在原项目中增量修改，不迁移云端，不修改模型、认证或访问策略。

## 修改文件与行为

- dist/motion-domain.js：纯数字运动约束校验、圆周弧段解卷绕、开闭端点、象限、坐标 / 参数区间、分支、排除轴和分问位置。数据不执行代码。
- dist/construction-board.js：统一解析、投影、拖动和依赖重算，非法位置不接受。分问驱动姿态独立保存；无限制覆盖不删除原构造。
- dist/motion-protection.js、dist/index.html：折叠式范围查看 / 设置，题设只读、手动点可编辑；无合法位置原子回滚，支持撤销。播放使用相同校验，平面动点不虚构自动路径。
- dist/learning-ui.js、dist/classroom.js：学生 / 教师切换小问停止播放并关闭无限制移动。题稿与刷新恢复读回原题基准，避免探索后的半轴被误当成题设。
- 恢复时优先使用保留的原题快照重建基准，兼容旧版探索后重复刷新误捕获的参数；固定命名点坐标也进入基准，手动追加点不删除。实际自由拖动定点仍使用独立覆盖，关闭 / 刷新清除覆盖。
- dist/question-bank.js、dist/question-bank.json：2025一卷18题参考图修订为2，明确第(i)问P是平面动点，第(ii)问才沿圆；R仍满足幂为3的反演。题库仍19项精选，不新增题目。
- 旧参考讲解升级需显式点击；先持久备份完整旧稿，再更新参考点线。保留手动对象、笔记、追问、解析及既有可见性。编号 / 点名冲突或备份失败时不升级。备份独立于正常题本去重，可从我的题本打开；不自动删除备份。
- 版本、PWA缓存、更新包必需模块、发布白名单、CI和使用说明同步更新。

## 仍有边界与下一阶段

已声明的数据式约束可执行，但不等于自动读懂任意题目的所有条件；不支持任意不等式区域的连续路径规划。范围设置只对手动追加的point_on开放，不篡改题设。旧稿自动适配只对明确参考来源的已修订图，不用于自由AI回答。

现有Worker不重新部署；前端共享数据协议已具备范围校验，并不宣称云端模型已自动输出全部新约束。国内云端网络可达性及2022一卷21、2023二卷21、2024一卷16、2025一卷18自由输入推理 / 建图缺口仍在。

下一阶段优先补自由输入的“答案→构造→独立核验”通路，继续使用有出处原题回归，再完善教师分步联动；不堆叠未批准的新入口。
