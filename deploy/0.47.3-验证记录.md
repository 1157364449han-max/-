# 0.47.3 最终切线补全

继承 [0.47.2 验证记录](0.47.2-验证记录.md) 的手机连接恢复、答案辅助构造及视野修复。0.47.2 已完成全套 CI 与 Pages 发布，最终验收又定位到下述边界，因此递增版本交付，不让桌面更新器错过同版本文件变更。

## 修改

- `dist/index.html`：题干要求切线时，复用结构化回复中的外点切点及其对应曲线补出遗漏切线，动态依赖与小问作用域保留。已有切线不重复创建；实际构造失败不加入，不猜接触点坐标。
- `tests/scene_consistency_browser_smoke.cjs`：以 2023 全国Ⅰ卷第 6 题的既有输入，模拟两切点存在、两切线缺失的协议数据，断言图中恰好两个切点与两条切线。测试不是实际模型调用，不代表总体正确率。
- 版本、离线缓存、下载包、文档和发布清单同步。访问口令持续为“董老师666”，本机公开入口继续隐藏，不调整云端模型、额度、费用或凭证。

## 验收

0.47.2 本机 Python 204 通过/1 符号链接夹具跳过、24 组 Node 和 50 组浏览器通过；视野与冲突修复后又完成 8 组和 3 组相关回归。0.47.3 使用完整数学、浏览器、构建及部署 CI 门禁，结果与实际网址、下载包校验、D 盘备份见本轮独立交接记录。失败不会绕过检查上线。

辅助构造识别仍为有限语法及数值检查，不是一般证明器或任意轨迹消参；原卷内置覆盖基线没有变化。未直接操作用户真实手机，浏览器移动视窗连通不证明该 Wi-Fi 可达。下一阶段继续真实原卷、独立核验、复杂轨迹及实际手机测试，不堆入口。
