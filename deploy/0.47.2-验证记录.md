# 0.47.2 手机连接恢复与答案辅助图形

日期：2026-10-01（北京时间）。沿用现有项目，解析几何技能用于核对答案、参数与图形的一致性及退化边界；没有新增独立程序，没有删除旧功能，也没有把数值图形当作一般性证明。

## 修改与原因

1. `dist/runtime.js`：流式授权失败也按发送时会话核对，迟到旧 401 不清掉续期 token；非法本地会话不误认已授权。普通 JSON 请求超时覆盖响应正文，异常 JSON 不误报网络中断；健康探测保留具体限流原因。
2. `dist/learning-ui.js`、`dist/index.html`：离线事件使旧健康结果失效，恢复网络时若旧探测未结束则排队检测；手动重试在 navigator 已在线时可检查实际网络，避免漏发 online 事件造成永久离线。设备离线、网络不可达、超时、服务异常、限流和会话过期分别提示。口令登录复用健康数据，本次限流不自动重新调用模型，也不在清理时立即刷成绿色。
3. 新增 `dist/answer-geometry.js`：只识别最终答案中明确描述的中点、垂足、点间连接、主曲线上点的切线、直线交点与两切线交点；使用已有可定位点和动态构造，不从文字猜坐标。自动对象有数量上限、稳定依赖、小问共享与幂等性；负面或条件性描述不当作绘图命令。用户对象保留；已有同名点的当前位置与明确关系不符时报告冲突。
4. `dist/scene-audit.js`：构造数值环境对齐画板平移中心、焦点、第二条弦与固定点，不再将有名称却无实交点视为已经呈现。检查题干及答案提及的点、答案切线、缺顶点多边形，增加垂足的在线和垂直条件检查。
5. `dist/learning-ui.js`：图形不完整或关系冲突直接在解析区提示，详情可展开；重新核对读取当前图形，关系检查在副本中进行，不修改用户画板。
   `dist/index.html` 的首次载图和“适配视图”同时容纳可见题设点、动态交点及辅助点，修复“点已经算出但被主曲线视野裁掉”；拖动帧不自动调整用户视野。
6. 版本配置、Service Worker、更新包必需模块、发布文件清单、说明与 CI 同步。底层本机代码仍保留但公开入口隐藏，访问口令持续为“董老师666”，未调整云端模型、配额、费用或私有凭证。

## 验证

- Windows Python 全量 205 项：204 通过，1 项文件符号链接夹具因主机不允许创建而跳过；实际 Windows 联接点拒绝检查通过。
- Node 全量 24 组；新增 28 项答案构造属性检查：坐标、真实依赖、移动重算、共享小问、重复执行、拒绝伪造、原对象保护与冲突提示。授权回归新增迟到流式错误、响应正文超时、异常 JSON 和非法会话数据。
- 浏览器新增公开云端单入口手机状态与答案辅助构造测试，使用 2022 北京第 10 题作为已有出处的原题输入。模拟模型回复只用于协议/画板测试，不代表实际模型正确率。保留引擎测试使用明确的测试夹具，不重新开放公开本机入口。
- 本地全量浏览器 50 组通过；随后补充视野适配与关系冲突复查，8 组相关回归及最终 3 组重点回归通过。正式发布仍以完整 CI 的数学、浏览器、构建与部署门禁为准，发布后状态在本轮交接记录报告。
- 既有原卷基线 12 道不同题、18 小问仍为内置完成标记 14/18，2022 北京第 10 题仍没有内置完整求解与作图。新浏览器测试中云端回复可建图，不意味着该题已经被内置引擎解出。

## 边界与下一阶段

- 辅助构造读取是有限语法与数值核对，不是完整自然语言理解、全题证明器或任意轨迹消参器。云端 AI 仍可能产生错误，尚未覆盖结论不得宣称核验正确。
- 网络事件与手机尺寸测试在浏览器中复现，没有操作用户实际手机。不能由电脑/移动视窗登录成功断言用户 Wi-Fi 已恢复；网页提示允许 Wi-Fi 与移动数据对比。
- 共享限流保持原配置，次数和费用不扩大；稳定性仍受服务商及实际终端网络影响。
- 下一阶段优先扩大有出处原卷回归、向量数量积范围、轨迹定义域/独立核验与实际手机触控测试，不堆新按钮。
