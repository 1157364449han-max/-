# 董解析 0.45.0 验证记录

## 本阶段已实现

- 不读取题库答案：由原题数值定点、轴平行准线的等距条件建立抛物线。平移、交换轴、反向开口统一采用应用现有约定：横向 minor²=4p·direction·axial，p 是焦点到顶点的距离。
- 距离平方展开、消元、原距离非负及反向回代保证轨迹等价。焦点在准线上属于退化，未伪造抛物线；斜准线、受限轨迹、距离倍数或偏移、复合目标等拒绝套用。
- 三个顶点在抛物线上的矩形，统一缩放为 Y=X²，推导相邻割线斜率积为 -1。导数在 t=1/√2 给出辅助函数下界，首个放缩取等需 t=1，二者不兼容；严格有 L>12√3p。这不是最小值或下确界的声明。
- 首问显示真实依赖的动点 P、焦点、准线、垂足和距离线段。次问显示一例合法矩形；选择矩形后可调中间顶点坐标和邻边斜率。其它顶点保持联动，顶点重合显示退化。小问图层、草稿恢复与原题/探索区分保持。
- 通用梯度切线只完成方程不能替代夹角、面积、轨迹或一般性证明；固定多边形的一次读数不能证明不等式。未覆盖目标标为待推导，保留已完成构造和更完整的模型答案。
- 修复 y=±x 的省略系数解析；题干/答案同小问的矩形和显式准线不重复绘制或标注。

- 142 个 Python 测试通过，包含独立 SymPy 恒等式、导数、反向回代、退化和复合目标；不向 SymPy 传入未受限的用户文本表达式。
