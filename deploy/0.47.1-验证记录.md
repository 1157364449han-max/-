# 0.47.1 发布前修复与云端单入口

本批在 0.47.0 的现有功能上修复，不重写项目、不删除底层解题引擎、不下载或删除用户模型。解析几何技能用于检查答案、参数和构造是否一致，以及是否把数值样本或部分结果误当完整证明。

## 已复现并修复的问题

1. 保存探索场景后重开，原题基准被探索参数替代。“还原本题”现在使用单独保存的原场景；旧草稿可从保留的原解答场景恢复，没有基准时如实说明。
2. “清除手动对象”原先清空全部对象，包括题设及答案中的 M 等构造。现只清除用户对象，题设和推导保留，操作可撤销。
3. 显式零半径、非有限中心或参数被默认值掩盖；非法文本用滑块修正后仍残留错误状态。现拒绝非法主曲线、保持原图，合法修正清除校验错误；完成文字参数编辑可撤销，探索状态随撤销恢复。
4. 只答焦点却把同时要求的面积标为完成。浏览器和 Python 以有界目标词汇检查既有计算覆盖，复合目标、未知量及不属于该曲线的特征保持待推导；不把任意含等号的问题当作“重复标准方程”。
5. 椭圆焦点弦证明步骤使用原例题常量，面积比 10/3 被误取分母。现从当前参数推导，保留分数，并以更换离心率与比例作回归。
6. AI 空白答案、未知编号、待完成证明义务或截断仍可能显示整问完成。统一云端和回复导入的数据与构造检查，完成数量由实际小问状态计算，不采信模型自报总数。
7. 场景合并跨类型按名称匹配、覆盖手动对象、ID 冲突、依赖与 feature 名称引用漏重映射。现保护用户对象，按类型匹配并维护完整依赖关系；无效构造拒绝导入。
8. 更换图片后旧 OCR 结果仍可写入识别窗口。旧任务与当前文件不相符时不应用结果。
9. 服务繁忙仍扣每日模型次数。先取得并发租约；上游拒绝、网络失败或非 SSE 返回退回日计数；已受理流式推理即使中断仍计数，不承诺取消已发生的供应商计费。
10. 服务拒绝过期会话却被解释为掉线，旧请求可能清掉新会话。授权和网络状态分别提示，过期回到输入口令状态；延迟旧回复不覆盖新授权。检测复用已取得的健康数据，手机探测超时留出网关和网络传输时间。
11. 404、503、下载页面或新版本 HTML 可能覆盖当前离线主页。只缓存同版本、成功的 HTML 主页；错误时使用已有安全缓存，不把新版资源混入旧缓存。
12. 更新包未检查新增数学模块及统一版本，也可覆盖模型、凭证、用户数据或通过联接点写入其它目录。现安装前拒绝这些情况，保留原文件，不删除旧备份。

## 当前入口

按用户发布要求，公开界面暂时只显示“云端解题”，隐藏本机方式、复制粘贴和模型下载入口；保留相应代码及浏览器对已覆盖结论的独立复算。旧本机选择迁移为云端，断线不会推荐不可见的入口，也不会把内置答案冒充云端回答。画板、题库、题本、拍照识字、参数和教学功能保留。

桌面快捷方式默认打开正式网页，电脑和手机共用发布版本，无须安装运行环境。管理员仍可用启动脚本的 `--local` 参数运行既有后台，但不是当前公开解题入口。

## 剩余边界

- 这不是任意高中题的通用证明器。云端生成答案仍可能错误，独立复算只覆盖已实现题型；没有核验依据时不宣称数学正确。
- 本轮手机状态回归使用浏览器移动视窗和触控模拟；没有直接操作用户实际手机。电脑认证成功不能证明手机所在 Wi-Fi 一定能访问 Workers 地址，网络问题仍须区分。
- 保持现有共享限流，不擅自增加推理费用。公共试用建议说明“AI 生成、需核对”，下一阶段优先扩展有出处原卷测试、独立核验和复杂图形覆盖，而不是继续堆按钮。
- 访问口令持续为“董老师666”。不变更 API 凭证，不把凭证加入公开网页或发布包。
