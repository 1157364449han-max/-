# 0.44.0：点名避让与解析步骤定位

## 第一阶段：标注可读性

根因：点名固定偏移 (+7,-7)，y 轴刻度偏移 (+4,-3)，北京2022第12题的 F₂/2 与 F₁/−2 会重叠；旧检查只验证对象存在，没有覆盖标注可读性。

改为统一屏幕空间布局：先收集点名/注释与坐标轴文字边界，再按题设点优先摆放；必要时白底、短引线。同位置名称合并显示、相同名称不重复印字，保留源对象与依赖。不同世界坐标的近邻点不按屏幕距离合并。屏幕外的点不强拉回标签；位置缓存上限512，切题重置。

文件：dist/label-layout.js、dist/index.html、tests/label_layout_tests.cjs、tests/label_layout_browser_smoke.cjs。

11项布局单元测试通过，包括大平移坐标近邻点及常见LaTeX点名；桌面原卷样例、手机320/390、DPR2触屏、缩放、平移、拖点及重复重绘通过。图形坐标/参数未被标签布局改写。鼠标悬浮的KaTeX坐标、动点命名和焦点弦切线/轨迹保持回归。

## 第二阶段：解析与画板联动

步骤按钮把原始文本交给已有图形名称匹配器，只定位当前可见、可解析的点、线、曲线和合法多边形。没有匹配及缺失对象如实提示，不用文字制造新对象，不改方程。切换小问、改题、删除/隐藏相关对象、切换图稿或还原图形清除过期选择。标签在高亮之后绘制，保持可读。

文件：dist/step-highlight.js、dist/learning-ui.js、dist/learning-ui.css、dist/index.html、tests/step_highlight_tests.cjs、tests/step_graph_link_browser_smoke.cjs。

已通过名字/下标/撇号、英文词误匹配防护、旧场景清除，以及真实北京2022第19题的键盘/点击、状态、隐藏项、题稿恢复、复制/阅读/打印和手机布局回归。

## 第三阶段：版本缓存一致性

离线资源和回退页面只查询当前worker版本缓存桶。显式脚本版本与worker不同，不忽略查询参数，不拿旧模块替代；缓存中的精确版本仍可使用。普通资源与API绕过保持。新增service_worker_version_tests.cjs验证当前版本、跨版本获取/拒绝错误回退、精确版本缓存、vendor、离线导航与API不缓存。

首轮全量测试曾遇到一次页内“attach”异常，单项重跑及随后完整41组均通过；不能据此断言已经定位该偶发异常。后续继续跟踪安装中缓存清理/更新竞态，新版本缓存约束单独验证，不冒称证明了所有加载竞态已消除。

## 验证结果与边界

最终运行124项Python、15组Node合约与41组实际浏览器流程，全部通过；专项截图经过目视检查。云端推理流程使用协议模拟，本轮未消耗共享模型额度；真实高考试题使用内置复算及已有题库数据。发布包及正式网页另行验收。

- 这是布局与名称定位改进，不增加云端模型的数学正确率承诺，不改变共享次数、费用配置、访问口令或凭证。
- 完全饱和的画面仍可能没有足够空间；标签不会静默丢弃，必要时通过引线移位。任意复杂LaTeX标签仍不是Canvas的完整排版功能。
- 名称定位可能把同名系数与几何名称混淆，当前界面明确说明“按名称”，不是完整步骤语义理解。
- 独立内置原卷基线仍为12题18问、8问完成标记，不是总体正确率。一般证明、复杂轨迹与更多原卷仍待扩展。
- 网页、桌面、离线缓存更新到0.44.0；云端网关无功能改动，本轮不重新部署网关。
