# 0.43.3：流式传输和正文分别限长

0.43.2 正式复测出现 HTTP 200，但浏览器报告“云端响应过长”，本次没有得到完成答案。旧限制把所有 SSE 事件的重复协议元数据也计入 1.5 MB 上限，可能先于正文保护拒绝合法长回复。

传输字节上限改为有界 8 MiB，正文累计和单个未消费片段仍限 100000 字符，300 秒截止、不完整 finish_reason 和错误事件检查保留；不会把部分回复冒充答案。模型 max_tokens、日配额、并发、访问口令和凭证不变。

## 测试和边界

- 124 个 Python 测试、12 组 Node 合约与 39 组实际浏览器继续回归；一致性合约保留 108 项。
- 浏览器协议测试：超过旧 1.5 MB 上限的元数据与正常正文通过；超过 8 MiB 的传输拒绝；超过 100000 字符的正文拒绝；错误和中断不替换之前完成的答案。
- 协议模拟不是模型数学能力。正式复测须单独留存原始输出和最终答案；只有完整传输且答案及图形核对通过才计该样例通过。
- 内置真题基线仍为 12 道、18 问，完成标记 8/18，不是总体正确率。复杂题仍有未覆盖部分，少量模型样例不证明通用正确。
